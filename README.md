# Mi YouTube

Versión 1.1.0 para Android, basada en el motor libre de NewPipe 0.29.0 para acceder por Internet a contenido compatible sin requerir una clave de YouTube Data API.

## Objetivo
- Búsqueda y reproducción desde Internet.
- Sin catálogo local de videos.
- Historial, favoritos y ajustes locales.
- Compatible con Android 6.0+ según la base NewPipe 0.29.0.
- Interfaz en español cuando el dispositivo está configurado en español.
